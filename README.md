# 卡牌对决

`卡牌对决` 是一款受杀戮尖塔启发的回合制 Web 卡牌游戏。玩家选择角色，通过出牌、管理能量、观察敌人意图和选择关卡奖励来推进 30 层分支冒险，或挑战无尽模式。

项目使用 Python + Flask 提供后端 API，前端使用原生 HTML、CSS 和 JavaScript 实现单页游戏界面，前后端均采用模块化架构。

## 当前功能

### 游戏核心

- **9 个角色**：无畏锋刃、共鸣之风、灼疫使者、裁决之盾、血色暗影、棘光圣者、福音齿轮、黑血祭师、蚀毒秘使
- **10 类敌人**：哥布林、史莱姆、火焰领主、寒冰法师、暗影领主、毒沼史莱姆、熔岩犬、镜像怪、护卫队长、诅咒法师
- **4 种游戏模式**：经典模式、关卡模式、无尽模式、自定义模式
- **30 层分支关卡**，支持简单、困难、地狱三种难度
- **无尽模式**：无层数上限，每 10 层出现一个小 Boss，敌人难度每 5 层递增
- **竖直展开地图**：全屏 SVG 连线地图，支持滚轮/拖拽/键盘导航，节点颜色编码，当前节点脉冲发光
- **相邻路线连接**：每个节点只连接位置相邻的下一层节点，参考杀戮尖塔规则
- **拖拽出牌**：可将手牌或技能直接拖拽到目标角色身上
- **敌人意图提前显示**：攻击、防御、强化和特殊行动，数据驱动 AI 意图池
- 每回合基础最大能量为 3，卡牌或技能获得的能量可超过最大值
- 角色技能每回合只能使用一次

### 关卡与成长

- **关卡奖励**：回血、强化、最大生命、完全恢复、升级卡牌、删除卡牌、遗物、下一轮攻击/防御
- **金币系统**：战斗结束奖励金币，可在商店节点购买物品
- **商店节点**：9 种商品（生命恢复、完全恢复、力量药水、护盾药水、删牌、升级、体魄强化、能量核心、随机遗物）
- **非战斗节点**（营火/商店/事件）：弹窗反馈结果，无战斗
- **Boss 前固定营火**：提供恢复和净化
- **失败重试**：战斗节点可重试（保留金币/遗物/牌组），非战斗节点不可重试
- **遗物系统**：10 个被动遗物，战斗开始自动生效

### 视觉与音效

- **章节动态背景**：8 个章节各有独特的 Canvas 渐变背景和粒子效果
- **程序化音效系统**：基于 Web Audio API 生成 16 种音效（出牌、受击、格挡、治疗、胜利、失败等）
- **设置面板**：声音开关、音量控制、登录/退出账号按钮（预留）
- **浮动伤害数字**：伤害/治疗/格挡分别用不同颜色显示
- **卡牌飞出动画**：出牌时卡牌飞向目标
- **回合横幅**：回合切换时显示玩家/敌人回合提示
- **敌人死亡消散**：敌人被击败时的渐隐动画
- **屏幕震动**：大伤害触发屏幕震动反馈
- **抽牌滑入**：新抽卡牌从右侧滑入手牌区
- **低血量暗角**：HP < 30% 时红色暗角警告，HP < 15% 时脉冲暗角危险提示

### 图鉴与收集

- **图鉴系统**：卡牌、敌人、遗物、统计四个标签页，数据持久化
- **敌人图鉴预测**：遇到过的敌人显示完整数据，未遇到的显示轮廓 + ??? 占位
- **角色解锁系统**：初始 3 个角色，通过累计胜场逐步解锁其余 6 个

### 工程质量

- **模块化架构**：后端路由拆分为 6 个蓝图模块，前端 JS 拆分为 7 个功能模块
- **配置外置**：后端 `src/config.py` 和前端 `static/js/config.js` 集中管理所有常量
- **状态缓存优化**：`get_state()` 使用脏标记缓存，避免重复序列化
- **事件委托**：UI 交互使用事件委托模式，减少内存泄漏
- **CSS 性能**：使用 `contain`、`will-change`、`overscroll-behavior` 等优化渲染
- **响应式设计**：使用 `clamp()` 和 `min()` 函数适配不同屏幕尺寸
- **无框设计**：游戏界面与网页无缝融合，滚动应用于整个页面
- **安全配置**：secret_key、全局异常处理、输入校验、原子写入、XSS 防护
- 25 张头像资源（19 SVG + 6 PNG），覆盖所有角色和敌人
- 支持鼠标操作、拖拽和键盘快捷键

## 快速开始

建议使用 Python 3.10 或更高版本。

```bash
pip install -r requirements.txt
python main.py
```

启动后浏览器会自动打开本地游戏页面。默认从 `127.0.0.1:5000` 开始寻找可用端口，如果端口被占用会自动尝试后续端口（5000-5010）。

## 游戏模式

### 经典模式

经典模式是一场独立战斗，适合快速体验角色和敌人机制。

| 难度 | 敌人配置 |
|---|---|
| 普通 | 哥布林、毒沼史莱姆 |
| 精英 | 熔岩犬、护卫队长 |
| Boss | 诅咒法师、镜像怪 |

### 关卡模式

关卡模式包含 30 层分支路线。每层 2-3 个节点可选，路线采用相邻连接（每个节点只连接下一层中位置相邻的 1-2 个节点）。玩家通关后先选择奖励，再从可选分支中选择路线，最终汇合到 Boss 关。

地图采用全屏竖直展开布局：
- 右上角 🗺️ 图标显示进度，点击展开
- 路线选择时自动展开
- 鼠标滚轮滚动、拖拽平移、键盘 ↑↓←→ 导航
- 节点颜色区分：红色=战斗、金色=精英、蓝色=事件、绿色=营火、紫色=商店、深红=Boss

| 路线类型 | 风险 | 奖励倾向 | 战斗 |
|---|---|---|---|
| 普通战 | 中 | 普通升级、基础成长 | 是 |
| 精英 | 高 | 遗物、高概率升级 | 是 |
| 事件 | 中 | 随机回血、失血换奖励 | 否 |
| 营火 | 低 | 恢复、净化、删牌 | 否 |
| 商店 | 低 | 金币交易 | 否 |
| Boss | 最高 | 通关胜利 | 是 |

Boss 前（第 29 层）固定为营火节点。

| 难度 | 特点 |
|---|---|
| 简单 | 标准敌人配置，适合熟悉角色 |
| 困难 | 敌人生命和伤害更高 |
| 地狱 | 多敌人组合更多，机制压力更强 |

#### 失败处理

战斗失败弹窗提供三个选项：
- **重试当前关卡**：仅战斗节点，保留金币、遗物和牌组，重置生命和临时 buff
- **重新开始**：回到当前难度第一层
- **回主菜单**：退出关卡模式

#### 金币与商店

战斗结束后根据难度奖励金币（简单 5-10，困难 8-14，地狱 12-18），层数越高金币越多。

商店节点随机出现在层 5-20 之间，提供以下商品：

| 商品 | 价格 | 效果 |
|---|---|---|
| 生命恢复 | 15💰 | 回复 25 HP |
| 完全恢复 | 30💰 | HP 回满 |
| 力量药水 | 12💰 | 下一轮攻击 +3 |
| 护盾药水 | 10💰 | 下一轮防御 +8 |
| 删牌 | 20💰 | 随机删除一张牌 |
| 升级卡牌 | 18💰 | 随机升级一张牌 |
| 体魄强化 | 22💰 | 最大生命 +10 |
| 能量核心 | 35💰 | 最大能量 +1 |
| 随机遗物 | 40💰 | 获得一个随机遗物 |

### 无尽模式

无尽模式无层数上限，初始生成 10 层地图，剩余 ≤5 层时自动扩展 10 层。每 10 层出现一个小 Boss（暗影领主、火焰领主、镜像怪、寒冰法师、诅咒法师轮流出现），敌人难度每 5 层提升一个等级。支持简单、困难、地狱三种难度。

| 特性 | 说明 |
|---|---|
| 初始层数 | 10 层，动态扩展 |
| 小 Boss 间隔 | 每 10 层 |
| 难度递增 | 每 5 层提升敌人等级 |
| 地图生成 | 随机生成，15% 商店概率，精英与事件交替 |

## 遗物系统

遗物是关卡模式中的被动奖励，主要从精英、事件和营火节点获得。当前有 10 个简单遗物，例如战斗开始获得格挡、力量、能量、祝福、骷髅、回响，或给敌人施加中毒和烧伤。

已拥有遗物会显示在玩家状态栏，鼠标悬停可查看效果说明。

### 自定义模式

自定义模式允许玩家设置玩家生命值，并添加 1 到 5 个敌人。敌人的类型、生命值和攻击力都可以调整，也可以使用预设组合快速开始。

## 状态效果

| 状态 | 效果 |
|---|---|
| 力量 | 增加攻击伤害 |
| 格挡 | 抵消即将受到的伤害 |
| 中毒 | 回合结算时造成伤害，随后层数减少 |
| 烧伤 | 回合结算时造成伤害，随后层数减少 |
| 流血 | 回合结算时造成伤害，随后层数减少 |
| 虚弱 | 降低攻击伤害 |
| 易伤 | 提高受到的伤害 |
| 诅咒 | 受到伤害时额外受到诅咒层数的伤害，随后逐回合减少 |

| 炮台 | 每回合开始自动攻击首个存活敌人 |
| 骷髅 | 每回合开始自动攻击首个存活敌人 |

状态图标支持鼠标悬停说明。战斗中有受击、格挡、技能、状态伤害等轻量动画反馈。

战斗状态通过 JSON 返回。前端不直接计算规则，只负责展示后端返回的状态。API 请求包含 8 秒超时处理和 HTTP 状态码校验。

## 安全特性

- **secret_key**：从环境变量读取，开发环境使用默认值
- **全局异常处理**：捕获未处理异常，防止泄露堆栈信息
- **输入校验**：`card_index` 和 `target_index` 必须为非负整数
- **原子写入**：图鉴数据使用临时文件 + 替换的原子写入方式，配合文件锁保证线程安全
- **XSS 防护**：前端 `escapeHtml()` 函数对用户输入进行 HTML 转义
- **键盘冲突防护**：快捷键在输入框聚焦时自动禁用
