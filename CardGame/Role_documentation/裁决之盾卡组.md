# 裁决之盾

血量：90

基础费用：3费

种族：人类

定位：护盾、防御、圣盾打击

主动技能：圣盾（下个回合开始时不会清除格挡）每回合可释放一次（消耗1费）

被动技能：每回合开始时获得6点格挡

卡组构成思路：使自身获得反击，反击会造成敌方攻击的1.5倍伤害、根据自身格挡数量造成单体伤害
