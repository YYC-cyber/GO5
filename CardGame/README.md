# 卡牌对决

`卡牌对决` 是一款受杀戮尖塔启发的回合制 Web 卡牌游戏。玩家选择角色，通过出牌、管理能量、观察敌人意图和选择关卡奖励来推进 30 层分支冒险。

项目使用 Python + Flask 提供后端 API，前端使用原生 HTML、CSS 和 JavaScript 实现单页游戏界面。

## 当前功能

- **9 个角色**：无畏锋刃、共鸣之风、灼疫使者、裁决之盾、血色暗影、棘光圣者、福音齿轮、黑血祭师、蚀毒秘使
- **10 类敌人**：哥布林、史莱姆、火焰领主、寒冰法师、暗影领主、毒沼史莱姆、熔岩犬、镜像怪、护卫队长、诅咒法师
- **3 种游戏模式**：经典模式、关卡模式、自定义模式
- **30 层分支关卡**，支持简单、困难、地狱三种难度
- **竖直展开地图**：全屏 SVG 连线地图，支持滚轮/拖拽/键盘导航，节点颜色编码，当前节点脉冲发光
- **相邻路线连接**：每个节点只连接位置相邻的下一层节点，参考杀戮尖塔规则
- **拖拽出牌**：可将手牌或技能直接拖拽到目标角色身上
- **敌人意图提前显示**：攻击、防御、强化和特殊行动
- 每回合基础最大能量为 3，卡牌或技能获得的能量可超过最大值
- 角色技能每回合只能使用一次
- **关卡奖励**：回血、强化、最大生命、完全恢复、升级卡牌、删除卡牌、遗物、下一轮攻击/防御
- **金币系统**：战斗结束奖励金币，可在商店节点购买物品
- **商店节点**：9 种商品（生命恢复、完全恢复、力量药水、护盾药水、删牌、升级、体魄强化、能量核心、随机遗物）
- **非战斗节点**（营火/商店/事件）：弹窗反馈结果，无战斗
- **Boss 前固定营火**：提供恢复和净化
- **失败重试**：战斗节点可重试（保留金币/遗物/牌组），非战斗节点不可重试
- **遗物系统**：10 个被动遗物，战斗开始自动生效
- **图鉴系统**：卡牌、敌人、遗物、统计四个标签页，数据持久化
- **视觉反馈**：低血量暗角、页面过渡动画、受击/格挡/技能动画、拖拽特效
- 25 张头像资源（19 SVG + 6 PNG），覆盖所有角色和敌人
- 支持鼠标操作、拖拽和键盘快捷键

## 快速开始

建议使用 Python 3.10 或更高版本。

```bash
pip install -r requirements.txt
python main.py
```

启动后浏览器会自动打开本地游戏页面。默认从 `127.0.0.1:5000` 开始寻找可用端口，如果端口被占用会自动尝试后续端口。

## 操作方式

| 操作 | 说明 |
|---|---|
| 点击手牌 | 使用卡牌，需要选择目标 |
| 拖拽手牌到敌人 | 直接出牌到目标 |
| 拖拽技能按钮到敌人 | 直接使用技能 |
| 点击敌人 | 为攻击或状态牌选择目标 |
| 点击技能按钮 | 使用角色技能 |
| 点击 🗺️ 图标 | 展开/关闭全屏地图 |
| 点击结束回合 | 进入敌人回合 |
| 点击抽牌堆/弃牌堆 | 查看对应牌堆详情 |
| 右键 | 取消当前选择 |
| `1-9` | 选择或打出对应位置的手牌 |
| `E` / `Enter` | 结束回合 |
| `Esc` | 取消选择或关闭弹窗/地图 |
| `R` | 打开重新开始/模式选择 |
| `H` | 显示或隐藏快捷键帮助 |
| ↑↓←→ | 地图模式下平移地图 |
| 鼠标滚轮 | 地图模式下纵向滚动 |
| 鼠标拖拽 | 地图模式下拖拽平移 |

## 游戏模式

### 经典模式

经典模式是一场独立战斗，适合快速体验角色和敌人机制。

| 难度 | 敌人配置 |
|---|---|
| 普通 | 哥布林、毒沼史莱姆 |
| 精英 | 熔岩犬、护卫队长 |
| Boss | 诅咒法师、镜像怪 |

### 关卡模式

关卡模式包含 30 层分支路线。每层 2-3 个节点可选，路线采用相邻连接（每个节点只连接下一层中位置相邻的 1-2 个节点）。玩家通关后先选择奖励，再从可选分支中选择路线，最终汇合到 Boss 关。

地图采用全屏竖直展开布局：
- 右上角 🗺️ 图标显示进度，点击展开
- 路线选择时自动展开
- 鼠标滚轮滚动、拖拽平移、键盘 ↑↓←→ 导航
- 节点颜色区分：红色=战斗、金色=精英、蓝色=事件、绿色=营火、紫色=商店、深红=Boss

| 路线类型 | 风险 | 奖励倾向 | 战斗 |
|---|---|---|---|
| 普通战 | 中 | 普通升级、基础成长 | 是 |
| 精英 | 高 | 遗物、高概率升级 | 是 |
| 事件 | 中 | 随机回血、失血换奖励 | 否 |
| 营火 | 低 | 恢复、净化、删牌 | 否 |
| 商店 | 低 | 金币交易 | 否 |
| Boss | 最高 | 通关胜利 | 是 |

Boss 前（第 29 层）固定为营火节点。

| 难度 | 特点 |
|---|---|
| 简单 | 标准敌人配置，适合熟悉角色 |
| 困难 | 敌人生命和伤害更高 |
| 地狱 | 多敌人组合更多，机制压力更强 |

#### 失败处理

战斗失败弹窗提供三个选项：
- **重试当前关卡**：仅战斗节点，保留金币、遗物和牌组，重置生命和临时 buff
- **重新开始**：回到当前难度第一层
- **回主菜单**：退出关卡模式

#### 金币与商店

战斗结束后根据难度奖励金币（简单 5-10，困难 8-14，地狱 12-18），层数越高金币越多。

商店节点随机出现在层 5-20 之间，提供以下商品：

| 商品 | 价格 | 效果 |
|---|---|---|
| 生命恢复 | 15💰 | 回复 25 HP |
| 完全恢复 | 30💰 | HP 回满 |
| 力量药水 | 12💰 | 下一轮攻击 +3 |
| 护盾药水 | 10💰 | 下一轮防御 +8 |
| 删牌 | 20💰 | 随机删除一张牌 |
| 升级卡牌 | 18💰 | 随机升级一张牌 |
| 体魄强化 | 22💰 | 最大生命 +10 |
| 能量核心 | 35💰 | 最大能量 +1 |
| 随机遗物 | 40💰 | 获得一个随机遗物 |

## 遗物系统

遗物是关卡模式中的被动奖励，主要从精英、事件和营火节点获得。当前有 10 个简单遗物，例如战斗开始获得格挡、力量、能量、祝福、骷髅、回响，或给敌人施加中毒和烧伤。

已拥有遗物会显示在玩家状态栏，鼠标悬停可查看效果说明。

### 自定义模式

自定义模式允许玩家设置玩家生命值，并添加 1 到 5 个敌人。敌人的类型、生命值和攻击力都可以调整，也可以使用预设组合快速开始。

## 角色概览

| 角色 | 生命 | 玩法定位 | 技能 | 被动 |
|---|---|---|---|---|
| 无畏锋刃 | 80 | 攻守平衡，力量成长 | 净化：清除全部负面状态（1费） | 战后回复 5 HP |
| 共鸣之风 | 65 | 连击、多段攻击、抽牌 | 回响：下一张牌不消耗费用并释放两次（2费） | 每 10 段伤害抽 1 张牌 |
| 灼疫使者 | 55 | 中毒、烧伤、状态爆发 | 元素爆发：群体伤害并施加毒和烧伤（2费） | 中毒和烧伤伤害提高 |
| 裁决之盾 | 90 | 护盾、防御、圣盾打击 | 圣盾：被动保留格挡，每回合获得护盾 | 每回合获得 6 格挡 |
| 血色暗影 | 60 | 流血、弃牌、低费爆发 | 暗影爆发：本回合获得能量和力量（1费） | 主动弃牌视为打出 |
| 棘光圣者 | 75 | 治疗、净化、祝福、反伤 | 神圣新星：治疗己方所有单位 | 治疗时对敌方造成伤害 |
| 福音齿轮 | 70 | 炮台、电池、模块成长 | 超频：强化炮台并获得能量（1费） | 每回合创建/成长炮台 |
| 黑血祭师 | 58 | 牺牲生命、骷髅、诅咒 | 亡者复苏：召唤/强化枯骨（1费） | 枯骨承担伤害 |
| 蚀毒秘使 | 68 | 毒、药剂、随机强化 | 万能药剂：随机强化并给敌人叠毒（1费） | HP 阈值切换中毒效果 |

所有主动技能每回合只能使用一次。技能按钮在使用后会显示"已使用"，下一回合开始后恢复可用。

| 哥布林 | 基础攻击、防御、强化 |
| 史莱姆 | 基础攻击、防御、强化 |

## 状态效果

| 状态 | 效果 |
|---|---|
| 力量 | 增加攻击伤害 |
| 格挡 | 抵消即将受到的伤害 |
| 中毒 | 回合结算时造成伤害，随后层数减少 |
| 烧伤 | 回合结算时造成伤害，随后层数减少 |
| 流血 | 回合结算时造成伤害，随后层数减少 |
| 虚弱 | 降低攻击伤害 |
| 易伤 | 提高受到的伤害 |
| 诅咒 | 受到伤害时额外受到诅咒层数的伤害，随后逐回合减少 |
| 祝福 | 每回合开始获得格挡 |
| 反伤 | 被攻击时对攻击者造成伤害 |
| 炮台 | 每回合开始自动攻击首个存活敌人 |
| 骷髅 | 每回合开始自动攻击首个存活敌人 |

状态图标支持鼠标悬停说明。战斗中有受击、格挡、技能、状态伤害等轻量动画反馈。
