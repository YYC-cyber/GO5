# 卡牌对决

`卡牌对决` 是一款受爬塔式卡牌游戏启发的回合制 Web 卡牌游戏。玩家选择角色，通过出牌、管理能量、观察敌人意图和选择关卡奖励来推进战斗。

项目使用 Python + Flask 提供后端 API，前端使用原生 HTML、CSS 和 JavaScript 实现单页游戏界面。

## 当前功能

- 9 个可选角色：勇者、精灵、巫师、圣骑士、刺客、牧师、机械师、亡灵法师、炼金术士
- 10 类敌人：哥布林、史莱姆、火焰领主、寒冰法师、暗影领主、毒沼史莱姆、熔岩犬、镜像怪、护卫队长、诅咒法师
- 3 种游戏模式：经典模式、关卡模式、自定义模式
- 30 层分支关卡，支持简单、困难、地狱三种难度
- 敌人意图提前显示，包含攻击、防御、强化和特殊行动
- 每回合基础最大能量为 3，卡牌或技能获得的能量可以超过最大值
- 角色技能每回合只能使用一次
- 关卡奖励包含回血、稀有强化、最大生命、完全恢复、升级卡牌、删除卡牌、遗物、下一轮攻击/防御
- 金币系统：战斗结束奖励金币，可在商店节点购买物品
- 商店节点：使用金币购买生命恢复、力量药水、护盾药水、删牌、升级、遗物等
- 非战斗节点（营火/商店/事件）无小怪，通过弹窗反馈结果
- Boss 前固定为营火节点，提供恢复和净化
- 支持抽牌堆和弃牌堆详情查看
- 19 个 SVG 头像资源，覆盖所有角色和敌人
- 支持鼠标操作和键盘快捷键

## 快速开始

建议使用 Python 3.10 或更高版本。

```bash
pip install -r requirements.txt
python main.py
```

启动后浏览器会自动打开本地游戏页面。默认从 `127.0.0.1:5000` 开始寻找可用端口，如果端口被占用会自动尝试后续端口。

## 操作方式

| 操作 | 说明 |
|---|---|
| 点击手牌 | 使用卡牌 |
| 点击敌人 | 为攻击或状态牌选择目标 |
| 点击技能按钮 | 使用角色技能 |
| 点击结束回合 | 进入敌人回合 |
| 点击抽牌堆/弃牌堆 | 查看对应牌堆详情 |
| 右键 | 取消当前选择 |
| `1-9` | 选择或打出对应位置的手牌 |
| `E` / `Enter` | 结束回合 |
| `Esc` | 取消选择或关闭弹窗 |
| `R` | 打开重新开始/模式选择 |
| `H` | 显示或隐藏快捷键帮助 |

## 游戏模式

### 经典模式

经典模式是一场独立战斗，适合快速体验角色和敌人机制。

| 难度 | 敌人配置 |
|---|---|
| 普通 | 哥布林、毒沼史莱姆 |
| 精英 | 熔岩犬、护卫队长 |
| Boss | 诅咒法师、镜像怪 |

### 关卡模式

关卡模式包含 30 层分支路线。每层提供 2-3 个节点可选，玩家根据自己的血量、牌组强度和金币选择最优推进路线。玩家通关后先选择奖励，再进入独立路线选择界面挑选下一关，最终汇合到 Boss 关。

路线选择界面会展示当前路线图、已走过节点、当前节点和可选分支。玩家选完路线后回到战斗页面，进入对应关卡。玩家生命值、力量、能力牌效果和牌组变化会在关卡之间继承。负面状态、手牌、格挡和能量会在过关后清理。

| 路线类型 | 风险 | 奖励倾向 | 是否有战斗 |
|---|---|---|---|
| 普通战 | 中 | 普通升级、基础成长 | 是 |
| 精英 | 高 | 遗物、高概率升级、稀有强化 | 是 |
| 事件 | 中 | 随机回血、失血换奖励、获得诅咒 | 否 |
| 营火 | 低 | 恢复、净化、删牌 | 否 |
| 商店 | 低 | 金币交易、购牌、回血 | 否 |
| Boss | 最高 | 通关胜利 | 是 |

事件、营火和商店节点为非战斗节点，进入后触发弹窗界面显示结果。商店节点可以用金币购买物品，事件节点触发随机效果，营火节点净化状态并回复生命。

Boss 前（第 29 层）固定为营火节点。

| 难度 | 特点 |
|---|---|
| 简单 | 标准敌人配置，适合熟悉角色 |
| 困难 | 敌人生命和伤害更高 |
| 地狱 | 多敌人组合更多，机制压力更强 |

每关胜利后可选择一项奖励。奖励会根据路线类型调整，当前不会新增普通卡牌，主要围绕续航、成长、遗物、升级和精简牌组展开。

#### 金币与商店

战斗结束后根据难度奖励金币（简单 5-10，困难 8-14，地狱 12-18），层数越高金币越多。金币显示在角色 HP 旁边。

商店节点随机出现在层 5-20 之间，提供以下商品：

| 商品 | 价格 | 效果 |
|---|---|---|
| 生命恢复 | 15💰 | 回复 25 HP |
| 完全恢复 | 30💰 | HP 回满 |
| 力量药水 | 12💰 | 下一轮攻击 +3 |
| 护盾药水 | 10💰 | 下一轮防御 +8 |
| 删牌 | 20💰 | 随机删除一张牌 |
| 升级卡牌 | 18💰 | 随机升级一张牌 |
| 体魄强化 | 22💰 | 最大生命 +10 |
| 能量核心 | 35💰 | 最大能量 +1 |
| 随机遗物 | 40💰 | 获得一个随机遗物 |

## 遗物系统

遗物是关卡模式中的被动奖励，主要从精英、事件和营火节点获得。当前有 10 个简单遗物，例如战斗开始获得格挡、力量、能量、祝福、骷髅、回响，或给敌人施加中毒和烧伤。

已拥有遗物会显示在玩家状态栏，鼠标悬停可查看效果说明。

### 自定义模式

自定义模式允许玩家设置玩家生命值，并添加 1 到 5 个敌人。敌人的类型、生命值和攻击力都可以调整，也可以使用预设组合快速开始。

## 角色概览

| 角色 | 生命 | 玩法定位 | 技能 |
|---|---:|---|---|
| 勇者 | 80 | 攻守平衡，力量成长 | 净化：清除全部负面状态 |
| 精灵 | 65 | 连击、多段攻击、抽牌 | 回响：下一张牌释放两次 |
| 巫师 | 55 | 中毒、烧伤、状态爆发 | 元素爆发：群体伤害并施加毒和烧伤 |
| 圣骑士 | 90 | 护盾、防御、圣盾打击 | 圣盾：被动保留格挡，每回合获得护盾 |
| 刺客 | 60 | 流血、弃牌、低费爆发 | 暗影爆发：本回合获得能量和力量 |
| 牧师 | 75 | 治疗、净化、祝福、反伤 | 神圣新星：治疗自身并群体伤害 |
| 机械师 | 70 | 炮台、电池、模块成长 | 超频：强化炮台并获得能量 |
| 亡灵法师 | 58 | 牺牲生命、骷髅、诅咒 | 亡者复苏：召唤骷髅并治疗 |
| 炼金术士 | 68 | 毒、药剂、随机强化、状态转换 | 万能药剂：随机强化并给敌人叠毒 |

所有主动技能每回合只能使用一次。技能按钮在使用后会显示"已使用"，下一回合开始后恢复可用。

## 敌人概览

| 敌人 | 主要机制 |
|---|---|
| 哥布林 | 基础攻击、防御、强化 |
| 史莱姆 | 基础攻击、防御、强化 |
| 火焰领主 | 高生命和高伤害压力 |
| 寒冰法师 | 状态压力和中后期威胁 |
| 暗影领主 | Boss 级生命和伤害 |
| 毒沼史莱姆 | 喷毒，施加中毒 |
| 熔岩犬 | 灼咬，攻击并施加烧伤 |
| 镜像怪 | 模仿玩家上一张牌的气势并施加易伤 |
| 护卫队长 | 为全体敌人提供格挡 |
| 诅咒法师 | 塞入诅咒牌并施加诅咒 |

## 状态效果

| 状态 | 效果 |
|---|---|
| 力量 | 增加攻击伤害 |
| 格挡 | 抵消即将受到的伤害 |
| 中毒 | 回合结算时造成伤害，随后层数减少 |
| 烧伤 | 回合结算时造成伤害，随后层数减少 |
| 流血 | 回合结算时造成伤害，随后层数减少 |
| 虚弱 | 降低攻击伤害 |
| 易伤 | 提高受到的伤害 |
| 诅咒 | 受到伤害时额外受到诅咒层数的伤害，随后逐回合减少 |
| 祝福 | 每回合开始获得格挡 |
| 反伤 | 被攻击时对攻击者造成伤害 |
| 炮台 | 每回合开始自动攻击首个存活敌人 |
| 骷髅 | 每回合开始自动攻击首个存活敌人 |

状态图标支持鼠标悬停说明。敌人意图也会显示具体效果，例如"毒液：3伤害 + 2中毒""守护：全体+10格挡"。战斗中有受击、格挡、技能、状态伤害等轻量动画反馈。
