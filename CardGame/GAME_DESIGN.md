# 卡牌对决游戏设计文档

## 项目定位

`卡牌对决` 是一款轻量级回合制卡牌战斗游戏。核心体验来自三件事：根据敌人意图规划出牌、围绕角色牌组形成不同打法、在分支关卡中通过奖励和路线选择调整推进方向。

当前版本在较小代码规模内实现可玩、可扩展、便于调试的卡牌战斗框架。

## 设计目标

| 目标 | 当前实现 |
|---|---|
| 快速开始 | 运行 `python main.py` 后自动打开浏览器 |
| 角色差异 | 9 个角色拥有不同名称、初始牌组和技能 |
| 策略决策 | 敌人意图提前显示，玩家可根据意图选择攻击、防御或叠状态 |
| 短局体验 | 经典模式提供单场战斗 |
| 长线体验 | 关卡模式提供 30 层分支路线、过关奖励、金币商店和路线选择 |
| 自定义验证 | 自定义模式可快速测试敌人组合 |
| 内容扩展 | 卡牌、角色、敌人都以类和配置表组织 |
| 视觉反馈 | 低血量暗角、页面过渡动画、受击/格挡/技能动画、节点发光效果 |

## 游戏循环

一场战斗由玩家回合和敌人回合交替组成。

```text
战斗开始
  ↓
玩家回合开始：重置能量、重置技能使用状态、触发回合开始能力、抽牌
  ↓
敌人决定下一步意图并显示给玩家
  ↓
玩家出牌（点击或拖拽到目标）、使用技能、选择目标
  ↓
玩家结束回合：结算状态、弃掉手牌
  ↓
敌人按意图行动
  ↓
敌人结算状态
  ↓
判断胜负，未结束则进入下一回合
```

玩家可以在回合内打出多张卡牌，只要能量足够。能量界面显示为 `当前能量/最大能量`，例如 `6/3`；卡牌或技能获得的能量可以超过最大值。每个角色的技能每回合只能使用一次，下一回合开始时恢复。

## 模式设计

### 经典模式

经典模式用于快速战斗，不继承关卡进度，也不发放过关奖励。它适合测试角色牌组、验证敌人机制和快速体验战斗节奏。

| 模式 | 敌人 |
|---|---|
| 普通 | 哥布林、毒沼史莱姆 |
| 精英 | 熔岩犬、护卫队长 |
| Boss | 诅咒法师、镜像怪 |

### 关卡模式

关卡模式包含 30 层分支路线。每层 2-3 个节点可选，玩家根据自己的血量、牌组强度和金币选择最优路线。玩家通关后先选择奖励，再从多个下一关节点中选择路线，最终汇合到 Boss 关。玩家生命值、力量、能力类成长、牌组升级和删牌结果会在关卡之间保留。负面状态、手牌、格挡和能量会在过关后清理。

#### 路线连接规则

路线连接采用相邻映射规则：每个节点只能连接到下一层中位置相邻的 1-2 个节点，这与杀戮尖塔的路线规则一致。

| 本层→下层 | 左节点连接 | 中间节点连接 | 右节点连接 |
|---|---|---|---|
| 2→2 | 下层左 | — | 下层右 |
| 2→3 | 下层左+中 | — | 下层中+右 |
| 3→2 | 下层左 | 下层左+右 | 下层右 |
| 3→3 | 下层左 | 下层中 | 下层右 |

该规则确保所有下层节点都至少被一个上层节点连接，路线不会出现断连。

#### 地图界面

关卡地图采用全屏竖直展开布局，参考杀戮尖塔的地图设计：

- 右上角小地图图标（🗺️）显示当前进度，点击展开全屏地图
- 路线选择时自动展开地图
- 竖直排列的节点，SVG 连线连接相邻节点
- 鼠标滚轮上下滚动浏览地图
- 鼠标拖拽平移地图
- 键盘 ↑↓←→ 平移，Esc 关闭
- 已走节点金色高亮，当前节点脉冲发光，可选节点蓝色闪烁
- 节点颜色编码：红色=战斗、金色=精英、蓝色=事件、绿色=营火、紫色=商店、深红=Boss
- 底部路线选择栏展示可选分支详情

| 路线类型 | 风险 | 奖励倾向 | 是否有战斗 | 设计意图 |
|---|---|---|---|---|
| 普通战 | 中 | 普通升级、基础成长 | 是 | 标准战斗节点，提供稳定推进节奏 |
| 精英 | 高 | 遗物、高概率升级、稀有强化 | 是 | 牌组强势时用更高战斗压力换更强成长 |
| 事件 | 中 | 随机回血、失血换奖励、获得诅咒 | 否 | 弹窗反馈随机结果，提供不确定性 |
| 营火 | 低 | 恢复、净化、删牌 | 否 | 弹窗反馈休整结果，玩家主动整理牌组 |
| 商店 | 低 | 金币交易、购牌、回血 | 否 | 使用金币购买物品，在中段随机出现 |
| Boss | 最高 | 通关胜利 | 是 | 所有路线最终汇合的决战节点 |

事件、营火和商店为非战斗节点，进入后触发弹窗界面显示结果。商店节点可以用金币购买物品，事件节点触发随机效果，营火节点净化状态并回复生命。Boss 前（第 29 层）固定为营火节点。

#### 失败重试

战斗失败后弹出失败弹窗，提供三个选项：

- **重试当前关卡**：仅战斗节点可用，保留金币、遗物和牌组，重置生命和临时 buff
- **重新开始当前难度**：回到当前难度的第一层重新开始
- **回到主菜单**：退出关卡模式

非战斗节点（营火、商店、事件）失败时隐藏重试按钮。

#### 金币系统

战斗结束后根据难度和层数奖励金币。金币显示在角色 HP 旁边。

| 难度 | 金币范围 |
|---|---|
| 简单 | 5-10 |
| 困难 | 8-14 |
| 地狱 | 12-18 |

层数每增加 5 层，金币 +1。

#### 商店系统

商店节点随机出现在层 5-20 之间，共 4-6 个。商店界面全屏覆盖，显示当前金币和可用商品。

| 商品 | 价格 | 效果 |
|---|---|---|
| 生命恢复 | 15💰 | 回复 25 HP |
| 完全恢复 | 30💰 | HP 回满 |
| 力量药水 | 12💰 | 下一轮攻击 +3 |
| 护盾药水 | 10💰 | 下一轮防御 +8 |
| 删牌 | 20💰 | 随机删除一张牌 |
| 升级卡牌 | 18💰 | 随机升级一张牌 |
| 体魄强化 | 22💰 | 最大生命 +10 |
| 能量核心 | 35💰 | 最大能量 +1 |
| 随机遗物 | 40💰 | 获得一个随机遗物 |

购买后即时生效，商品消失。离开商店后进入路线选择。

#### 过关奖励

过关奖励包含：

| 奖励 | 效果 |
|---|---|
| 回复生命 | 回复 20 点生命 |
| 稀有强化 | 力量 +1，最大生命 +5 |
| 最大生命 | 最大生命 +8，并回复 8 点生命 |
| 完全恢复 | 回复至满血，每局只能出现并使用一次 |
| 特殊强化 | 最大能量 +1 |
| 下一轮攻击 | 下一场战斗伤害 +3 |
| 下一轮防御 | 下一场战斗开始获得 8 格挡 |
| 补给休整 | 净化负面状态并回复 18 点生命 |
| 升级卡牌 | 随机提供一张未升级卡牌作为升级选项 |
| 删除卡牌 | 从当前牌组中删除一张牌 |
| 遗物 | 获得一个简单被动效果 |

当前版本不再提供"过关获得新卡"的奖励。

### 遗物系统

遗物是关卡模式的被动成长，主要由精英、事件和营火节点提供。当前版本包含 10 个简单遗物，效果覆盖战斗开始获得格挡、力量、能量、祝福、骷髅、回响、治疗，或对敌人施加中毒和烧伤。

遗物在每场战斗开始时自动生效，战斗结束后临时 buff 清空，下次战斗开始时遗物重新生效。

### 自定义模式

自定义模式用于自由配置敌人。玩家可以选择角色，设置玩家生命值，添加 1 到 5 名敌人，并调整敌人的生命和攻击力。支持预设组合快速开始。

### 角色定位

| 角色 | 生命 | 核心打法 | 技能 |
|---|---:|---|---|
| 无畏锋刃 | 80 | 攻守平衡，力量成长 | 净化（1费） |
| 共鸣之风 | 65 | 连击、多段攻击、抽牌 | 回响（2费） |
| 灼疫使者 | 55 | 中毒、烧伤、状态爆发 | 元素爆发（2费） |
| 裁决之盾 | 90 | 格挡保留、护盾转伤害 | 圣盾（被动） |
| 血色暗影 | 60 | 流血、低费、弃牌爆发 | 暗影爆发（1费） |
| 棘光圣者 | 75 | 治疗、净化、祝福、反伤 | 神圣新星 |
| 福音齿轮 | 70 | 炮台、电池、模块成长 | 超频（1费） |
| 黑血祭师 | 58 | 生命换资源、骷髅、诅咒 | 亡者复苏（1费） |
| 蚀毒秘使 | 68 | 中毒、随机强化、状态转换 | 万能药剂（1费） |

### 技能规则

角色技能消耗能量，且每回合只能使用一次。技能是否可用由以下条件共同决定：

- 当前战斗未结束
- 当前能量大于等于技能消耗
- 本回合尚未使用过技能

裁决之盾的技能是被动技能（每回合自动获得护盾且格挡可保留），前端不显示可点击主动技能按钮。

### 角色被动

| 角色 | 被动技能 |
|---|---|
| 无畏锋刃 | 战斗结束后回复 5 点生命值 |
| 共鸣之风 | 每造成 10 段伤害从卡组中抽取一张牌 |
| 灼疫使者 | 中毒和烧伤造成的伤害提高 |
| 裁决之盾 | 每回合开始时获得 6 点格挡 |
| 血色暗影 | 主动丢弃的手牌视为打出（不消耗费用） |
| 棘光圣者 | 治疗自身时对敌方随机单体造成治疗量一半的伤害 |
| 福音齿轮 | 回合开始时创建炮台，若炮台存在则成长一次 |
| 黑血祭师 | 受到伤害时若枯骨存在则优先由枯骨承担 |
| 蚀毒秘使 | 血量低于50%时中毒伤害视为回血 / 高于50%时中毒伤害翻倍 |

## 卡牌设计

### 卡牌分类

| 类型 | 作用 |
|---|---|
| 攻击 | 对敌人造成伤害，通常受力量影响 |
| 技能 | 提供格挡、治疗、抽牌、能量或状态效果 |
| 能力 | 提供持续效果，例如铁壁、祝福、炮台、骷髅 |

### 目标规则

攻击牌和敌方状态牌通常需要选择敌人。自身目标牌会自动作用于玩家，不需要选择目标。

自身目标牌包括防御、治疗、能力、抽牌、能量、召唤、模块成长等类型。

玩家可以通过两种方式出牌：点击手牌再点击目标，或将手牌/技能直接拖拽到目标角色身上。拖拽过程中敌人卡片会显示金色高亮提示。

### 升级规则

卡牌升级会改变实际数值，而不仅是描述文本。升级可能影响：

- 伤害
- 格挡
- 治疗量
- 抽牌数
- 能量获得
- 状态层数
- 持续能力数值

## 状态设计

| 状态 | 持有者 | 结算规则 |
|---|---|---|
| 力量 | 玩家/敌人 | 提高攻击伤害 |
| 格挡 | 玩家/敌人 | 抵消伤害，默认回合结束清空 |
| 中毒 | 玩家/敌人 | 回合结束受到层数伤害，层数 -1 |
| 烧伤 | 玩家/敌人 | 回合结束受到层数伤害，层数 -1 |
| 流血 | 玩家/敌人 | 回合结束受到层数伤害，层数 -1 |
| 虚弱 | 玩家/敌人 | 降低攻击伤害，回合结束层数 -1 |
| 易伤 | 玩家/敌人 | 受到伤害增加，回合结束层数 -1 |
| 诅咒 | 玩家/敌人 | 受到伤害时额外受到诅咒层数伤害，回合结束层数 -1 |
| 祝福 | 玩家 | 每回合开始获得格挡 |
| 反伤 | 玩家 | 被敌人攻击时反击伤害 |
| 炮台 | 玩家 | 每回合开始自动攻击首个存活敌人 |
| 骷髅 | 玩家 | 每回合开始自动攻击首个存活敌人 |

## 敌人设计

### 基础敌人

哥布林、史莱姆、火焰领主、寒冰法师和暗影领主使用通用意图逻辑：攻击、防御和强化。低血量时更倾向防御，力量较高时更倾向攻击。

### 机制敌人

| 敌人 | 特殊意图 | 效果 |
|---|---|---|
| 毒沼史莱姆 | 毒液 | 造成少量伤害并施加中毒 |
| 熔岩犬 | 灼咬 | 攻击并施加烧伤 |
| 镜像怪 | 镜像 | 模仿玩家上一张牌的气势，造成伤害并施加易伤 |
| 护卫队长 | 守护 | 为全体敌人提供格挡 |
| 诅咒法师 | 诅咒 | 往玩家弃牌堆加入诅咒牌，并施加诅咒 |

敌人意图在玩家回合开始时确定并展示。敌人行动时不会重新随机意图，这样玩家的决策信息是可信的。

前端会展示详细意图文案，例如"毒液：3伤害 + 2中毒""守护：全体+10格挡"。状态图标支持鼠标悬停说明，降低复杂状态的理解成本。

## 前端界面

### 页面结构

页面结构由 `static/index.html` 定义，主要区域包括：

- **主菜单**：单人模式、多人模式（待开发）、图鉴、设置（待开发）、关闭游戏
- **角色选择弹窗**：9 个角色，展示名称、血量、牌组、技能和被动
- **模式选择弹窗**：经典模式（普通/精英/Boss）、关卡模式（简单/困难/地狱）、自定义模式
- **战斗界面**：敌人区域、战斗日志、手牌区域、奖励面板、玩家状态栏
- **地图面板**：全屏竖直地图，可拖拽/滚轮/键盘导航，SVG 连线
- **商店界面**：全屏覆盖，展示金币和商品
- **事件/营火弹窗**：触发后显示结果
- **失败弹窗**：重试、重新开始、回主菜单
- **图鉴系统**：卡片、敌人、遗物、统计四个标签页
- **快捷键帮助弹窗**
- **牌堆详情弹窗**（抽牌堆/弃牌堆）

### 视觉反馈

- 低血量暗角：HP < 30% 时红色暗角警告，HP < 15% 时脉冲暗角危险提示
- 页面过渡动画：主菜单到选择弹窗的缩放淡入淡出效果
- 受击/格挡/技能/状态伤害动画
- 卡牌拖拽效果：半透明、缩小、抓取光标
- 敌人卡片拖入目标区域时金色发光
- 地图节点：当前节点脉冲发光，可选节点闪烁，Boss 节点红色脉冲

### 操作方式

| 操作 | 说明 |
|---|---|
| 点击手牌 | 使用卡牌，需要选择目标 |
| 拖拽手牌到敌人 | 直接出牌到目标 |
| 拖拽技能按钮到敌人 | 直接使用技能到目标 |
| 点击敌人 | 为攻击或状态牌选择目标 |
| 点击技能按钮 | 使用角色技能 |
| 点击结束回合 | 进入敌人回合 |
| 点击抽牌堆/弃牌堆 | 查看对应牌堆详情 |
| 右键 | 取消当前选择 |
| `1-9` | 选择或打出对应位置的手牌 |
| `E` / `Enter` | 结束回合 |
| `Esc` | 取消选择或关闭弹窗/地图 |
| `R` | 打开重新开始/模式选择 |
| `H` | 显示或隐藏快捷键帮助 |
| ↑↓←→ | 地图模式下平移地图 |

### 图鉴系统

图鉴记录玩家在游戏中遇到的卡牌、敌人和遗物。数据存储在 `collection_data.json`。支持四个标签页：

- **卡牌**：展示已收集/未收集的卡牌名称
- **敌人**：展示已遇到的敌人
- **遗物**：展示已获得的遗物
- **统计**：展示各角色的游戏统计

| 方法 | 路径 | 说明 |

## 扩展约定

新增卡牌时，在 `src/core/card.py` 新增类，并继承 `Card`。如果卡牌作用于玩家自身，需要把中文牌名加入 `WebBattle.SELF_TARGET_NAMES`。

新增角色时，在 `CHARACTER_TEMPLATES` 中添加角色配置，并在前端角色选择区域添加对应选项。

新增敌人时，优先在 `Enemy.choose_intent()` 和 `Enemy.take_turn()` 中补充特殊意图。如果敌人需要出现在关卡模式，还需要更新 `level_mode.py` 的关卡配置；如果需要出现在自定义模式，还需要更新前端 `ET` 敌人列表。

新增头像时，把 SVG 或 PNG 放入 `static/images`，并更新 `WebBattle.CHARACTER_IMAGES`。
